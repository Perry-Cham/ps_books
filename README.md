# P's Books

P's Books is a modern Flutter-based ebook reader and downloader application. It supports multiple formats and integrates with Google Drive for cloud storage of your library.

## Features

- **Multi-format Support:** Read EPUB, PDF, FB2, and Microsoft formats.
- **Google Drive Integration:** Sync your library across devices using Google Drive.
- **Book Downloader:** Search and download books from various providers.
- **Library Management:** Organize your collection, track reading progress, and maintain a wishlist.
- **Study Mode:** Features for tracking study targets and timetable management.
- **Beautiful UI:** A dark-themed, modern interface designed for comfortable reading.

## Getting Started

### Prerequisites

- Flutter SDK
- Android Studio / Xcode (for mobile development)
- Google Cloud Console project (for Google Drive API access)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Perry-Cham/ps_books.git
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the application:
   ```bash
   flutter run
   ```
